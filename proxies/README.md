# Published proxy lists

These files are generated by GitHub Actions after live validation. Do not manually add candidates to these outputs.

- all.txt includes protocol schemes.
- http.txt, https.txt, socks4.txt and socks5.txt contain protocol-specific address lists.
- http-connect.txt contains HTTP proxy endpoints that passed the fixed HTTPS destination test.
- strong.txt and strong/ contain repeat-tested endpoints above the configured score and latency thresholds.
- proxies.json and proxies.csv contain measured metadata.

The first refresh creates the files. A successful connectivity check is time-bounded and is not a guarantee of future availability or operator trust.
